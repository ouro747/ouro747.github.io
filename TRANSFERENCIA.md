# Transferência para outro chat

Para continuar este projeto em outra conversa:

1. Envie o arquivo ZIP completo do projeto para a nova conversa.
2. Na mesma mensagem, cole o conteúdo de `PROMPT-NOVO-CHAT.md` ou peça para o ChatGPT ler esse arquivo primeiro.
3. Informe que o objetivo inicial é colocar a versão atual online e, depois, continuar seção por seção.
4. Não envie apenas `index.html`: o projeto depende de `app.js`, `data.js`, `styles.css`, `assets/` e dos arquivos auxiliares.

A cópia exportada começa sem produtos cadastrados e foi preparada para ser a nova base oficial do projeto.
